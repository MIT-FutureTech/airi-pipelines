# classifier-tool

Example LLM-based classifier that categorizes documents.

## Links

- [GitHub repo](https://github.com/MIT-FutureTech/example-classifier)

## Tech

Python, OpenRouter API (Gemini / Claude)

## Inputs

- Airtable `Records` table — documents with `status=pending`

## Outputs

- Airtable `Records` table — updates `category`, `confidence`, `reasoning` fields

## How it runs

CLI: `python classify.py --limit 100`

Supports continuous mode with `--continuous` flag (polls every 60s).
