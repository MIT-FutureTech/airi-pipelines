# scraper-tool

Example scraper that discovers documents from external sources.

## Links

- [GitHub repo](https://github.com/MIT-FutureTech/example)

## Tech

Python, Streamlit, Google Custom Search API

## Inputs

- User-provided search queries via web UI

## Outputs

- Airtable `Records` table (title, link, snippet, status)

## How it runs

Manual — user triggers searches through a Streamlit UI.
