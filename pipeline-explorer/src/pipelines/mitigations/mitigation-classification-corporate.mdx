# LLM mitigation classification (corporate)

Classifies AI risk mitigation mentions from corporate documents into the hierarchical mitigation taxonomy. Uses the same two-stage approach as <NodeLink id="risk-classification">risk classification</NodeLink>: a relevance gate followed by taxonomy classification.

Part of the <NodeLink id="company-scraping">airi-orgrev-orglist</NodeLink> repo.

## Links

- [GitHub repo](https://github.com/MIT-FutureTech/airi-orgrev-orglist)
- Entry point: `llm_classification/classify.py`

## Tech

Python, OpenRouter, structured JSON output

## Inputs

- CSV of keyword mentions from <NodeLink id="pdf-keyword-extraction">PDF keyword extraction</NodeLink>
- Same input as risk classification — the two classifiers run independently on the same data

## Outputs

- Per-mention JSON files in `llm_classification/output/mitigation/classifications/`
- Assembled CSV (`classified.csv`) with taxonomy classifications
- Combined CSV joining risk + mitigation results by match_id

## How it runs

CLI: `python -m llm_classification.classify -i input.csv -p prompts/mitigation_prompt.md --type mitigation -w 20 --assemble`

## Notes

- Shares the mitigation taxonomy with <NodeLink id="mitigation-taxonomy-classification">airi-mitrev-classifier</NodeLink> (research papers path)
- Default model: Gemini Flash Lite via OpenRouter
